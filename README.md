# apexmedia.space

Website for Apex Media LLC (Dorado, Puerto Rico). Static HTML/CSS, deployed on Vercel.

- `index.html` home
- `services.html`, `work.html`, `work/jebin-john.html`, `clipsy.html`, `about.html`, `contact.html`
- `privacy.html`, `terms.html`
- `styles.css` shared design system
- `vercel.json` clean URLs + security headers

No build step. Edit and push; Vercel deploys automatically.

## 2026 site refresh

The homepage uses `home.css` and `home.js` for the new editorial design. The existing secondary pages keep their established layouts and share `styles.css`. Contact inquiries on every page open an email draft to `contact@apexmedia.space`.
